# 아이디어: 음성 명령 색깔 공 배달 미로 탈출 (시나리오 v1, 안)

- 제안자: @OH-BJ
- 날짜: 2026-11-21
- 상태: 팀 확정 전. 11/21 회의에서 테스트하면서 결정

## 한 줄 요약

사람이 말로 "왼쪽부터 1, 2, 3에 빨강 초록 파랑"이라고 시키면, 로봇이 미로를 돌아다니며 그 색 공을 찾아 손으로 잡고, 바구니 1·2·3에 순서대로 넣은 뒤 출구로 나간다.

## 문제와 동기

- 기존 버튼 시나리오는 키 스위치가 오지 않아 버튼을 그대로 만들기 어렵다 (나머지 부품은 도착).
- 공은 배선 없이 준비할 수 있고(공 + 받침대 + 우드락 바구니), "찾아서 집어 옮긴다"는 동작이 눈으로 보기에 직관적이다.
- 큰 틀(음성 → 계획 → 탐색 → 목표 찾기 → 손 동작 → 탈출)은 원래 시나리오와 같고, **목표 앞에서 손이 하는 일만 "누르기"에서 "잡기 + 놓기"로 바뀐다.**

## 동작 방식

```
① 음성 명령       "왼쪽부터 1, 2, 3에 빨강 초록 파랑"
② 계획 (VLM)      → {1번 바구니: 빨강, 2번: 초록, 3번: 파랑}
③ 탐색 (라이다)   미로를 돌며 SLAM 지도 + 내 위치
④ 공 찾기 (앞캠)  색 공 발견 → 지도에 "빨강 공 여기" 찍기 (말 안 한 색은 무시)
⑤ 다가가기        지도 경로로 공 앞까지 이동
⑥ 잡기 (VLA)      손 밑 카메라로 마지막 정렬 → 잡기
⑦ 넣기            바구니 앞으로 가서 해당 번호 바구니에 놓기
⑧ 판정 (바구니캠) 바구니 위 카메라가 "1번 빨강, 2번 초록, 3번 파랑" 확인
⑨ 반복            ⑤~⑧을 3번
⑩ 탈출            로봇이 출구 앞에 오면(초음파) + 3개 다 맞으면 → 피코 WH가 서보로 문 열기 → 통과
```

### 각 단계에서 쓰는 것

| 단계 | 입력 | 처리 | 출력 |
|---|---|---|---|
| 음성 인식 | 마이크 소리 | Qwen3-ASR | 글자 |
| 계획 | 글자 | VLM (Qwen3-VL-4B) + 코드 검사 | 바구니별 색 순서 (JSON) |
| 탐색·지도 | 라이다 스캔 | slam_toolbox | 지도 + 내 위치 |
| 공 찾기 | 앞 카메라 사진 | 색 픽셀 계산 (+ 필요하면 감지 모델) | 공 색 + 방향·거리 → 지도 좌표 |
| 이동 | 지도 + 목표 좌표 | 경로 계획 (Nav2 또는 간단한 코드) | 바퀴 속도 |
| 잡기·놓기 | 손 밑 카메라 + 손 상태 + 명령 | VLA (SmolVLA / ACT, 아이작 데이터로 학습) | 바퀴 속도 + 손가락 각도 |
| 바구니 판정 | 바구니 카메라 사진 | 색 픽셀 계산 (손이 빠진 뒤, 같은 결과가 2초 유지되면 확정) | 바구니별 공 색 → 정답 여부 |
| 출구 문 | 판정 결과(와이파이) + 출구 초음파 | 피코 WH (MicroPython) | 서보로 문 열기 |

## 필요한 하드웨어·기술

| 장비 | 위치 | 역할 |
|---|---|---|
| 라즈봇 V2 + AiHand | - | 이동 + 잡기 |
| 라이다 A1M8 | 차 위 | 벽 피하기, 지도, 내 위치 |
| 앞 카메라 (C270 예정) | 손보다 높은 곳, 앞을 봄 | 공 찾기, 색 구분 |
| 손 밑 카메라 (Camera Module 3) | 손 밑, 손가락 쪽을 봄 | 잡기 직전 정렬 (손등에 가려지는 문제 해결) |
| 노트북 (RTX 3060) | - | VLM, VLA 계산 (파이는 영상·센서를 보내고 명령을 받음) |
| 공 3개 + 가짜 공 1~2개 | 미로 곳곳 받침대 위 | 목표 / 방해물 |
| 받침대 (고무바닥 깔기) | - | 공을 손 높이에 맞추고 굴러가지 않게 |
| 우드락 바구니 3개 | 출발점 근처, 왼쪽부터 1·2·3 | 공 넣는 곳 |
| 바구니 카메라 (남는 웹캠) | 바구니 위에서 비스듬히, 노트북에 USB | 바구니에 들어간 공 색 판정 |
| 라즈베리파이 피코 WH + 서보모터 (아두이노 키트) | 출구 옆, 보조배터리 전원 | 와이파이로 "열어" 신호를 받아 문 열기 |
| 초음파 센서 (아두이노 키트) | 출구 문 앞 | 로봇 도착 감지 (5V 신호라 저항으로 전압 낮춰 피코에 연결) |
| (선택) 번호판 1~2장 | 바구니 앞 등 | 정확한 정렬이 필요할 때만, 라이다 위치가 흔들릴 때 보조 |
| (선택) 폰 초광각 + 삼각대 | 미로 모서리 위 | 발표 영상, 로봇 실제 경로 기록 (일반 웹캠으로 미로 전체를 담으려면 약 3m 높이가 필요해서 폰 초광각 추천) |

### 카메라 정리

| 카메라 | 위치 | 역할 |
|---|---|---|
| Camera Module 3 | 로봇 손 밑 | 잡기 |
| C270 | 로봇 앞 (손 위) | 공 찾기 |
| 남는 웹캠 1 | 바구니 위 | 판정 |
| 남는 웹캠 2 | - | 예비용 (라이다가 있어서 로봇에 추가로 달 필요 없음) |

### 바구니 판정 다른 방법 (참고)

| 방법 | 장단점 |
|---|---|
| **바구니 카메라 (선택)** | 색과 위치를 직접 확인, 배선 없음, 가장 정확 |
| 초음파 3개 + 로봇 카메라 색 | 초음파는 "몇 번 바구니에 들어왔는지"만 알고 색은 로봇이 잡을 때 본 걸로 판단. 작은 바구니에서 값이 흔들릴 수 있음 |
| RFID (키트 2개) | 바구니 3개에 리더가 1개 모자라고 읽는 거리가 3cm 안팎. 손바닥에 달아 "잡은 공 확인" 용도로는 가능성 있음 |

## 최소 데모 (MVP)

공 1개 + 바구니 1개: "빨강을 1번에 넣어" → 공 찾기 → 잡기 → 넣기.

## 확장 방향

- 공 3개 + 가짜 공 + 바구니 3개 전체 시나리오
- 대화 기능: TTS로 대답·진행 보고 ("빨강 넣었어요", "파랑은 아직 못 찾았어요"), 애매한 명령은 되묻기
- 멀티모달: 색 대신 동물 그림 공/카드, 표지판 힌트를 VLM이 읽고 길 고르기
- 카메라 영상만으로 지도 만들기 (MASt3R-SLAM) 를 라이다 지도와 비교

## 위험 요소

| 위험 | 대응 |
|---|---|
| **손 힘이 약해 공을 못 잡음 (가장 큼)** | 가볍고 적당한 크기 공(지름 6~7cm 스펀지·볼풀 공) 테스트. 안 되면 **Plan B: 원래 버튼 누르기 시나리오** (키 스위치 대신 마이크로 스위치·택트 스위치·압력 센서 + 우드락 판) |
| 잡고 달리다 떨어뜨림 | 천천히 이동, 공 크기·손가락 각도 조정 |
| 손이 라이다 시야를 가림 | 라이다를 손보다 높이 두거나, 가리는 각도는 무시하도록 설정 |
| 하얀 우드락 벽에서 SLAM 위치 흔들림 | 천천히 회전(초당 30도 이하), 필요하면 번호판 보조 |
| 모듈3 케이블이 손 밑까지 안 닿음 | 긴 리본 케이블 구매 |
| 시간 부족 | MVP(공 1개)부터 완성 후 확장 |
