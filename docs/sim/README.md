# 미로 탈출 3D 시뮬레이션

11/14 오프라인 미팅에서 정한 시나리오를 실제 재료 크기 그대로 브라우저에서 돌려 보는 시뮬레이션입니다.
설치 없이 링크만 열면 됩니다.

- **바로 열기:** https://taehyun35.github.io/T1_PathFinder_Rep/sim/ (GitHub Pages를 켠 뒤부터 열림)
- **내 컴퓨터에서 열기:** 이 폴더의 `index.html`을 더블클릭 (인터넷 연결 필요, 3D 라이브러리를 받아 옴)

## 무엇을 보여 주나요

1. 라즈봇이 미로에서 아직 안 본 곳을 찾아다니며 라이다로 2D 지도를 그림
2. 카메라로 벽의 색-숫자 단서 카드를 읽음 (예: 빨강 3)
3. 순서 카드를 읽고 색 순서대로 숫자를 이어 비밀번호를 만듦
4. 문 앞 키패드에 멈춰서 손가락(검지=1, 중지=2, 약지=3, 새끼=4)을 굽혀 누름
5. 맞으면 문이 열리고 탈출

손이나 차체가 벽에 닿는 움직임은 하지 않습니다. 좁아서 못 돌면 칸 안에서 자리를 옮기거나 옆으로 이동(메카넘)하고, 그래도 못 지나가면 다른 길로 갑니다.

## 크기 기준

| 항목 | 값 | 출처 |
|---|---|---|
| 바닥 | 4.5m × 2m (고무매트 0.9m × 2m 5장) | 11/14 회의록 |
| 벽 | 우드락 900×600mm, 5mm | 11/14 회의록 |
| 차 + 손 | 전체 길이 42cm, 폭 16cm, 높이 25cm | 실측 (11/17) |
| 차체 길이 | 23cm (어림값, 손 19cm) | 재면 바꾸기 |
| 카메라 | 시야각 66도 | 카메라 모듈 3 기본 렌즈 |
| 키 간격 | 19mm | 일반 키보드 |
| 손가락 끝 간격 | 22mm (어림값) | 재면 바꾸기 |

모든 값은 왼쪽 설정에서 바꿀 수 있고, 바꾸면 바로 다시 만들어집니다. 설정은 브라우저에 저장됩니다.

## 조작

- **▶ 시작:** 자동으로 탐색부터 탈출까지 진행 (빠르기 1~16배)
- **보기:** 전체(마우스로 돌리기) / 차 따라가기 / 위에서 / 로봇 카메라
- **직접 운전:** `W` `S` 앞뒤, `A` `D` 제자리 회전, `Q` `E` 옆으로, `1`~`4` 손가락 누르기, `Z` `X` 카메라 좌우

## 지금까지 돌려 보고 알게 된 것 (11/17, 실측 크기 기준)

- 차+손이 42cm라서, 제자리에서 돌 때 손끝이 그리는 원의 지름이 약 62cm입니다. 통로 50~60cm에서는 제자리 회전이 거의 안 됩니다.
- 통로 65cm면 6×3칸이 되고, 우드락 20장이 거의 딱 맞습니다.
- 키 간격(19mm)과 손가락 간격(22mm)이 다르면, 멈출 때 ±8mm만 틀어져도 비밀번호를 한 번에 맞히는 비율이 약 60%로 떨어집니다. 키 간격을 손가락 간격에 맞추면 거의 100%입니다.
