# 구현/실험: 말로 시키면 찾아서 잡고 내려놓기 (테스트 25·26)

## 목표

멘토님 시나리오는 "물건 3개를 3곳에 두고, 말한 물건을 잡고, 없으면 주먹"이다. 이걸 지금 장비(AiHand + 웹캠 + 마이크)로 할 수 있는지 확인했다.

## 구현 내용

부품을 이어 붙인 모듈식이다. VLA처럼 모델 하나가 다 하는 방식은 아니다.

1. **Whisper** (base, 명령 목록 힌트): 목소리 → 글자
2. 글자에서 "공" 또는 "스프레이"를 찾는다.
3. **YOLO-World** (ball, bottle): 웹캠 화면에서 그 물건의 상자를 찾는다.
4. 화면을 왼쪽 / 가운데 / 오른쪽 세 칸으로 나눈다. 상자 가운데가 들어간 칸의 손목 각도(150 / 90 / 30)로 손목을 돌린다. 10프레임 중 절반 이상 같은 칸일 때 확정한다.
5. 사람이 물건을 손바닥에 대 주면 꽉 쥐기(엄지 140, 검지 30, 나머지 20) → 3초 유지 → 손 펴서 내려놓기
6. 물건이 안 보이면 주먹, 말이 없으면(소리 최대값 0.03 미만) 움직이지 않음

## 실험 조건

- PC: i5-12400F, RTX 3060 12GB, USB 웹캠 640x480, USB 마이크
- 물건: 빨간 공, 흰 코 스프레이
- 회차마다 6초 동안 물건 놓기 → 3.5초 동안 말하기

## 결과

**테스트 25 (3곳 집기)**
- 손바닥은 손목 30에서 오른쪽, 90에서 정면, 150에서 왼쪽을 향했다.
- 세 방향 모두 물건을 사람이 대 줘야 잡을 수 있었다. 팔이 없어서 손이 물건 쪽으로 가지 못한다.
- 공과 스프레이는 잡혔다. 펜과 접는 부채는 손가락 위에 얹히기만 해서 제외했다.

**테스트 26 (전체 연결, 2회차 시도)**

| 회차 | 한 것 | 결과 | 말 끝 → 손목 명령 |
| --- | --- | --- | --- |
| 1 | 일부러 말하지 않음 | 소리 작음으로 무시, 안 움직임 (정상) | - |
| 2 | 공 잡아 | 가운데 칸 → 손목 90 | 0.53초 |
| 3 | 스프레이 집어 | 왼쪽 칸 → 손목 150 | 0.56초 |
| 4 | 스프레이를 눕혀 두고 스프레이 집어 | 안 보임 → 주먹 (정상) | 0.57초 |

- 말이 끝나고 손목이 움직이기까지 약 0.55초 걸렸다. 받아쓰기 0.1~0.16초, 물건 찾기 0.4초다.

## 문제와 해결

- 말을 하지 않았는데도 Whisper가 힌트 문장("공 잡아, 스프레이 집어, ...")을 그대로 받아쓴 적이 있었다. 그러면 말 없이도 로봇이 움직일 수 있다. 두 가지로 막았다.
  - 소리가 작으면 받아쓰지 않는다.
  - 받아쓴 글에 명령이 2개 이상 섞여 있으면 무시한다.
- 눕힌 스프레이는 웹캠이 알아보지 못했다. 물건은 세워 두는 것이 좋다.
