1. 저장소를 `C:\robot\T1_PathFinder_Rep`에 받는다. git이 있으면 `git clone https://github.com/TaeHyun35/T1_PathFinder_Rep.git C:\robot\T1_PathFinder_Rep`, 없으면 main.zip을 받아 `C:\robot`에 푼다.
2. 이 README 전체를 읽고 실험 순서(0~6)를 파악한다.
3. Python 3.11 이상이 있는지 확인한다. 없으면 설치 방법을 사람에게 알려 주고 기다린다.
4. `src\field_test`에서 `install.bat`을 실행해 설치한다 (pyserial, cryptography만 설치, 1분).
5. 이 노트북의 와이파이 IP 주소를 알려 준다 (`ipconfig`). VR 주소가 `https://<이 IP>:8443`이 된다.
6. micro:bit가 꽂혀 있으면 COM 포트를 찾아 알려 준다.
7. 사람이 원하면 `src\voice_pick\install.bat`도 백그라운드로 설치를 시작한다 (10분 이상, 인터넷 필요).
8. 준비가 끝나면 "준비 완료"와 함께, 사람이 쓸 명령을 정리해 준다: `hand.bat`, `vr.bat`, `vr.bat --car <파이IP>`, 파이에서 `python3 car.py wheels`.

- [ ] 라즈봇 V2 (배터리 충전), AiHand (전원), micro:bit USB 선, PICO 4 Ultra (충전)
- [ ] **줄자, 마스킹 테이프** (격자 표시), **주방 저울**, 500ml 물병 + 끈/집게
- [ ] 공, 스프레이, 5cm 정도 받침대 (컵, 상자), 두꺼운 책 2~3권

## 0. 준비 (15분)

### 0-1. 노트북
1. 이 폴더를 받습니다 (ZIP 풀기). 경로에 한글이 없는 곳이 좋습니다 (예: `C:\robot\field_test`).
2. Python 3.11이 없으면 설치 (https://www.python.org/downloads/, "Add python.exe to PATH" 체크).
3. `install.bat` 더블클릭 (1분).
4. voice_pick도 할 거면 **지금** `src\voice_pick\install.bat`도 같이 켜 둡니다 (10분 이상, 인터넷 필요). 다른 실험 하는 동안 깔립니다.

### 0-2. 네트워크 (가장 먼저 정하기)
노트북, 파이, 피코가 **같은 와이파이**에 있어야 VR → 차가 됩니다.
- 장소 와이파이가 기기끼리 못 보게 막혀 있으면 폰 핫스팟 하나에 셋 다 붙입니다.
- 파이가 새 와이파이에 붙으려면 파이 설정이 필요하니, 파이가 이미 아는 와이파이를 쓰는 게 제일 쉽습니다.
- 노트북에서 확인: `ping <파이IP>` 가 응답하면 OK.

### 0-3. 차 (파이)
노트북 명령창에서:
```
scp car\car.py <아이디>@<파이IP>:~/
ssh <아이디>@<파이IP>
python3 car.py wheels
```
- 바퀴가 하나씩 1초 돕니다. 화면에 나온 이름(FL 앞왼쪽, RL 뒤왼쪽, FR 앞오른쪽, RR 뒤오른쪽)과 실제 바퀴가 다르면 `car.py` 위쪽 `motor` 번호를, 뒤로 돌면 `invert`를 고칩니다 (`nano car.py`).
- `Raspbot_Lib를 못 불러왔습니다`가 나오면 Yahboom 드라이버가 없는 것입니다. Yahboom 이미지면 보통 들어 있습니다.

### 0-4. 손
1. micro:bit에 `hand\microbit-serial-range.hex`가 올라가 있는지 확인 (없으면 MICROBIT 드라이브에 끌어다 놓기).
2. `hand.bat` 실행 → `o`(펴기), `g`(쥐기), `w 30` / `w 150`이 되면 OK.

## 1. 무게·넘어짐 (25분) - 시뮬레이션 예측 확인

손이 달린 상태 그대로 합니다. 모든 시험은 **폰으로 옆에서 낮게** 찍습니다 (바퀴가 뜨는지 보이게).

**1-1. 무게 재기 (3분)**: 손만, 차 전체(손 포함), 공, 스프레이 무게를 저울로. 손이 차 바퀴 바깥으로 몇 cm 튀어나왔는지 줄자로.

**1-2. 매달기 (5분)**: 손바닥(또는 손끝)에 빈 물병을 끈으로 매달고 물을 조금씩 붓습니다. 반대쪽 바퀴가 뜨는 순간 멈추고 물병 무게를 잽니다. → "손에 몇 g까지 버티나". 500g 넘게 버티면 공(수십 g)은 걱정 없음.

**1-3. 기울이기 (3분)**: 손 반대쪽 바퀴를 천천히 들어 올려 차가 손 쪽으로 넘어가기 직전 각도를 수평계로 잽니다. 반대로 손 쪽을 들어서도 한 번. (넘어지면 받을 사람 대기)

**1-4. 주행 패턴 (12분)**: 파이에서 반복 가능한 명령으로 합니다.
```
python3 car.py run fwd 120 1.0      앞으로 1초 후 급정지
python3 car.py run right 150 1.0    옆 이동 후 급정지 (손이 오른쪽이면 이게 가장 위험)
python3 car.py run rotl 150 1.5     제자리 회전
```
방향은 fwd back left right rotl rotr, 세기는 80 / 150 / 255로 올려 갑니다. 조합마다 3번씩:
- 손 편 상태 → 공 쥔 상태 (`hand.py`에서 `g`) → 손목 30 또는 150으로 돌린 상태
- 결과: 괜찮음 / 흔들림 / 바퀴 뜸 / 미끄러짐 / 넘어짐
- 자유롭게 몰아 보려면 `python3 car.py teleop` (w a s d, q e 회전, 1 2 3 세기, x 끝)

**1-5. 손목 흔들기 (2분)**: 차 멈춘 상태로 `hand.py`에서 `r` (공 쥔 채 손목 30 → 150 → 90). 차가 흔들리는지.

## 2. 손으로 잡기 (20분) - 손목 꺾기 시뮬레이션 확인

**2-1. 받침대 빼기 (10회)**: 공을 5cm 받침대에 올려 손바닥 아래에 맞추고 `hand.py`에서 `t`. 3초 뒤 쥐면 받침대를 빼고 5초 들고 있는지. 스프레이도 같은 방법.

**2-2. 손 25° 기울이기 (10회)**: 사람이 차(또는 손)를 잡고 손을 약 25° 아래로 기울여 바닥 공 위에 놓고 `g`. 수평계로 각도 확인. → 시뮬레이션 예측: 25°면 바닥 공이 잡힘.

**2-3. 책으로 차 15° 기울이기 (10회)**: 손 반대쪽 바퀴 밑에 책을 넣어 손 쪽이 15° 내려가게 하고 바닥 공을 `g`. 차가 넘어가지 않는지도 같이 봅니다.

기록: 성공/10, 실패 이유 (손가락 위에 얹힘, 미끄러짐, 손이 바닥에 닿음 등).

## 3. 차 속도 재기 (10분) - VR → 차에 필요

차 앞에 테이프로 출발선을 붙이고:
```
python3 car.py calib fwd     2초 가면, 간 거리(cm)를 입력
python3 car.py calib left    옆으로 2초
```
각각 2번씩 해서 비슷한지 봅니다. 값은 파이의 `car_config.json`에 저장되어 서버가 씁니다.
그다음 `python3 car.py run fwd 120 1.67` (= 50cm 예상)으로 실제 50cm 가는지 확인.

## 4. VR 가리키기 정확도 (20분)

**바닥 격자**: 테이프로 X 표시 9개, 간격 50cm.
```
C1   C2   C3      (100cm 앞)
B1   B2   B3      (50cm 앞)
A1   A2   A3      (A2가 기준)
     ●  사람: A2에서 50cm 뒤에 서서 C 쪽을 봄
```
1. 노트북에서 `vr.bat` → 화면에 나온 `https://<노트북IP>:8443` 주소를 피코 브라우저에 입력. "안전하지 않음" 경고가 나오면 고급 → 계속.
2. **테스트 A** 버튼 → 눈앞 글자 "다음: A1"을 따라 가리키고 엄지·검지 집기.
3. A1, A3은 보정용(이 두 점으로 격자 위치를 맞춤), 나머지 7개가 오차로 기록됩니다. 노트북 터미널에 점마다 "오차 몇 cm"가 나옵니다.
4. 잘못 찍으면 노트북 터미널에 `u` + Enter. 한 라운드 끝나면 `n` + Enter로 새 라운드.
5. 라운드: 손 2번, 컨트롤러 2번, 가능하면 다른 팀원 1번.
6. 결과는 `vr\logs\accuracy_*.csv`. `s` + Enter로 요약.

녹화: 피코 자체 화면 녹화(패스스루 포함)를 켜고 하면 가리키는 모습이 남습니다.

## 5. 가리킨 곳으로 차 보내기 (20분)

1. 파이: `python3 car.py server`
2. 노트북: `vr.bat --car <파이IP>` (도착 후 손까지 쥐게 하려면 `vr.bat --car <파이IP> --hand`, micro:bit를 노트북에 연결)
3. 바닥에 차 출발 표시(차 중심)와, 그 **앞 1m**에 테이프 표시. 차 중심을 출발 표시에 맞추고 정면을 앞 표시로.
4. 피코에서 **테스트 B** → 차 중심 찍기 → 앞 1m 표시 찍기 (보정) → 보낼 곳 가리키고 집기.
5. 차가 앞으로 간 다음 옆으로 갑니다. 도착하면 **목표 테이프와 차 중심(또는 손) 사이 거리를 줄자로** 잽니다.
6. 목표 5곳 정도 (가까운 곳 30cm, 먼 곳 1m, 왼쪽, 오른쪽). 다음 목표는 차를 다시 출발점에 두지 않아도 이어서 됩니다.

손이 목표 위에 오게 하려면: 차 중심에서 손바닥까지 거리를 재서 `--hand-offset 앞,왼쪽` (m, 오른쪽은 -)으로 넣습니다. 예: 손이 차 오른쪽 25cm면 `--hand-offset 0,-0.25`.

`--hand`를 켜면 도착 후 손이 펴지고, 5초 안에 사람이 공을 손바닥에 대 주면 쥐고 3초 들고 있다가 놓습니다.

## 6. 시간 남으면

- `voice_pick` (테스트 25·26)을 팀원 노트북에서 다시: `src\voice_pick\run.bat --look` → `src\voice_pick\run.bat`. 결과가 내 PC(약 0.55초)와 같은지.
- 차 카메라로 바닥 공이 몇 m까지 보이는지 (미로 실험용).

## 끝나고

- 파이: `Ctrl+C`로 서버 끄기. 노트북 터미널 `q`.
- `vr\logs` 폴더, 폰 영상, 기록지 사진을 오병주에게 모아 주기 → 노션 테스트 기록에 정리.

## 안전

- 차는 바닥에서만, 책상 위 금지. 처음 주행은 세기 80부터.
- `car.py`의 모든 움직임은 시간이 지나면 저절로 멈춥니다. teleop은 키를 떼면 0.3초 뒤 멈춥니다. 급할 때 Ctrl+C.
- 피코는 오래 쓰면 뜨거워지니 한 번에 15분 이내로.
