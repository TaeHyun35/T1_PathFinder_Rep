## 단계

| 단계 | 하는 일 | 로봇 쪽 명령 (화면 버튼이 대신 실행) |
|---|---|---|
| 1 보정 | 바퀴 방향 확인, 제자리 한 바퀴, 실제 회전 속도 측정 | `mission.py run --station --vwalls vwalls.json --stage calib --no-hand` |
| 2 지도 생성 | 방 전체를 벽 따라 돌며 라이다 지도, 안 본 곳 찾아가기, 출발점 복귀 | `roommap.py run --yes ...` |
| 3 동물·탈출 위치 찾기 | 테이프 미로 안에서 카드와 2번 마커 위치 기억 -> `~/maze_home/demo_state.json` 저장 | `--stage find --find-cards dog,rabbit,...` |
| 4 말한 동물 찾아가기 | 저장한 기억으로 순서대로 카드 정면에 서기 | `--stage visit` (+ PC 스테이션이 순서 전달) |
| 5 탈출 | 기억한 2번 마커 앞에 서서 밀고 나가기 | `--stage exit` |

4, 5단계는 3단계가 성공한 뒤에 하고, 로봇은 테이프 네모 한가운데에 둬요 (방향은 조금 달라도 출발 사진과 360도 맞춰서 찾음).

## 새 노트북에서 처음 한 번

1. 파이썬 3.11 설치 (설치할 때 "Add python.exe to PATH" 체크)
2. 이 저장소 받기 (Code -> Download ZIP 또는 `git clone`)
3. **핫스팟**: 로봇(파이)은 원래 노트북 핫스팟에만 붙어요. 새 노트북의 모바일 핫스팟 이름과 비밀번호를 원래 것과 **똑같이** 바꾸면 로봇이 192.168.137.4 로 붙어요.
4. `src\tools\demo\install.bat` 실행 (필요한 것 설치, 몇 분 걸림)
5. 로봇 켜고 `src\tools\demo\setup_ssh.bat` 실행 -> 로봇 비밀번호 한 번 입력 -> "연결 성공"

## 시연 때

1. 핫스팟 켜기 -> 로봇 켜기 (1분 기다림)
2. `src\tools\demo\run_demo.bat` 실행 -> 검은 창은 켜 둔 채로, 열린 화면(깃허브 페이지)에서 단계 버튼 누르기
3. 4단계는 화면에서 동물 순서를 고르거나 "마이크로 말하기"
4. 멈출 때는 화면의 **멈춤** 버튼 (로봇이 바로 섬)

## 11/27 밤 실제로 확인한 것 / 남은 것

- 됨: 보정, 방 지도, 테이프 미로에서 카드 6장 + 탈출 위치 찾기 (45~90초), 음성 순서 받기, 출발점 복귀
- 고친 뒤 실제로 끝까지는 못 본 것: 4단계(카드 정면에 서기), 5단계
- 실제 로봇에서 찾은 원인과 고친 것: 실제 회전이 명령의 약 1.3배 -> 주행거리계 예측 보정, 느린 회전(45도/초 미만)은 바퀴가 헛돎 -> 회전은 45도/초 + 시간으로, 라이다 첫 사진이 덜 찍힘 -> 꽉 찬 사진 기다림, 카메라 0.3~0.5초 늦음 -> 멈춰서 보고 돌기
